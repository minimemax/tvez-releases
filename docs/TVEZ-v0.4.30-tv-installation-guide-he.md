# התקנת TVEZ 0.4.30-tv (Carmel)

קובץ ההתקנה: `TVEZ-v0.4.30-tv.apk`

המדריך מיועד למכשירי Android TV. אין להסיר את הגרסה הקיימת של TVEZ לפני העדכון.

## העברה באמצעות USB

1. הורד למחשב את הקובץ `TVEZ-v0.4.30-tv.apk` מדף הגרסה של TVEZ.
2. העתק את הקובץ לכונן USB וחבר אותו לסטרימר.
3. פתח בסטרימר מנהל קבצים, היכנס לכונן ה־USB ופתח את קובץ ההתקנה.
4. אם Android מבקש הרשאה להתקנה ממקור זה, אשר אותה עבור מנהל הקבצים וחזור למסך ההתקנה.
5. אם כפתור ההתקנה מוסתר, פתח „פרטים נוספים” או „Details”, גלול עד להמשך ובחר „התקן”.
6. בסיום בחר „פתיחה”.

## העברה באמצעות LocalSend

1. התקן את LocalSend גם במכשיר השולח וגם בסטרימר, וחבר את שניהם לאותה רשת Wi-Fi.
2. במחשב או בטלפון בחר ב־LocalSend שליחה של `TVEZ-v0.4.30-tv.apk`, ואז בחר את הסטרימר.
3. אשר את קבלת הקובץ בסטרימר ופתח אותו מתוך LocalSend או ממנהל הקבצים.
4. אם Android מבקש הרשאה להתקנה ממקור זה, אשר אותה עבור האפליקציה שפתחה את הקובץ וחזור להתקנה.
5. אם כפתור ההתקנה מוסתר, פתח „פרטים נוספים” או „Details”, גלול עד להמשך ובחר „התקן”.
6. בסיום בחר „פתיחה”.

הניסוח והמיקום של כפתורי Android עשויים להשתנות בין יצרנים וגרסאות מערכת.
