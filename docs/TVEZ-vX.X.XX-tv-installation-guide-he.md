# התקנת TVEZ

קובץ ההתקנה של הגרסה: **TVEZ-v1.0.0-tv-Hermon.apk**

המדריך מתאים למכשירי Android TV, לטלפונים ולטאבלטים עם Android.

אם TVEZ כבר מותקנת, אין להסיר את הגרסה הקיימת לפני העדכון. התקן את הקובץ מעל הגרסה הקיימת.

## התקנה ישירה בטלפון או בטאבלט

1. הורד את קובץ ההתקנה מדף גרסת TVEZ.
2. פתח את הקובץ שהורדת דרך הדפדפן או מנהל הקבצים.
3. אם Android מבקש אישור להתקנה ממקור זה, אשר לאפליקציה שפתחה את הקובץ וחזור להתקנה.
4. בחר **התקן**, ובסיום בחר **פתח**.

## התקנה באמצעות USB ב־Android TV

1. הורד את קובץ ההתקנה מדף גרסת TVEZ.
2. העתק אותו לכונן USB וחבר את הכונן לסטרימר או לטלוויזיה.
3. פתח את הקובץ באמצעות מנהל הקבצים במכשיר.
4. אם Android מבקש אישור להתקנה ממקור זה, אשר למנהל הקבצים וחזור להתקנה.
5. אם כפתור **התקן** מוסתר, פתח **פרטים נוספים / Details**, גלול להמשך ובחר **התקן**.
6. בסיום בחר **פתח**.

## התקנה באמצעות LocalSend

1. התקן את LocalSend במכשיר השולח ובמכשיר המקבל, וחבר את שניהם לאותה רשת Wi-Fi.
2. במכשיר השולח בחר לשלוח את קובץ ההתקנה ובחר את המכשיר המקבל.
3. אשר את הקבלה במכשיר המקבל.
4. פתח את הקובץ דרך LocalSend או דרך מנהל הקבצים.
5. אם Android מבקש אישור להתקנה ממקור זה, אשר לאפליקציה שפתחה את הקובץ וחזור להתקנה.
6. אם כפתור **התקן** מוסתר, פתח **פרטים נוספים / Details**, גלול להמשך ובחר **התקן**.
7. בסיום בחר **פתח**.

הניסוח והמיקום של כפתורי Android עשויים להשתנות בין יצרנים וגרסאות מערכת.
