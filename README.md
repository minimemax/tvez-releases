# TVEZ Releases

This repository hosts signed TVEZ APK releases and the metadata used by the in-app update checker. The private development source, signing keys, and test logs are not published here.

Download the current APK from the [Releases](https://github.com/minimemax/tvez-releases/releases) page. Compare its SHA-256 with the checksum published alongside the release before installing. Android requires your approval to install an APK from outside its app store, and TVEZ does not silently install updates.

Versions installed before the in-app updater was introduced need one manual update. After that, the app can notify you about a new release and offer a download that you approve.

For a bug report or suggestion, open an [Issue](https://github.com/minimemax/tvez-releases/issues). Do not post private stream URLs, access tokens, personal information, or unredacted device logs.
